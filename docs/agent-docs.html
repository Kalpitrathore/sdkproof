Your docs for AI agents work. Their size is what breaks them.

One sentence from React Router's own documentation fixes a failure nine times out of ten. The identical sentence, inside the 25 KB file it actually lives in, fixes it zero times out of ten. Meanwhile the bundles libraries publish for agents run to five megabytes.

The experiment

Two libraries, each with one task an AI assistant reliably gets wrong, and each with a sentence in its own documentation that names the fix. Ten trials per row. The only variable is how much text surrounds that sentence.

Nothing about the wording changed between the last two rows. React Router's sentence is "Important: meta receives loaderData; do not use deprecated data args." In the 25 KB pack it sits at line 182 of a 213-line file and the model writes data every time. On its own, the model writes loaderData.

So the failure is not comprehension, and it is not refusal. The model follows the instruction when it can find it. That is a retrieval problem, and it has the opposite fix from the one usually recommended.

Sizes span 2,217 characters to 5,673,960 — a factor of about 2,500 — under two filenames that promise the same thing. For tRPC, llms.txt is documentation. For Zod, it is 94% links. For TanStack Query, llms-full.txt is byte-identical to llms.txt. For Next.js and Stripe it 404s.

Put the two tables together and the problem is visible. A 76-byte instruction changes what a model writes. A 25 KB file containing the same instruction does not. And the direction the ecosystem is moving is 3.8 MB, 5.7 MB, 3.6 MB — bundles that are, on this evidence, the shape least likely to work.

What to do instead

Not "write better documentation" — the documentation is already right. The two sentences measured here were written by the libraries themselves, and both work.

Ship a short file containing only the things a model provably gets wrong. For React Router that is a handful of v8 renames. For Prisma it is the driver adapter and the removed datasourceUrl. Both fit in under 200 characters each. A complete documentation bundle is a different artifact for a different purpose, and it does not substitute for this.

Prisma's approach comes closest today: prisma init installs small, task-scoped skill files into your project, so nothing has to be fetched and each file is narrow. It is the only mechanism in this survey that works for a model with no network access.

Honest limits

One model (Claude Opus 5), two libraries, one failing task each, ten trials per cell, and a one-shot prompt rather than a real agent loop with retrieval. The minimal arm is close to handing the model the answer — its entire context is the correction — so this measures whether a salient instruction is followed, not whether realistic documentation works. That is still the useful half: it locates the failure in retrieval rather than in the model's willingness to comply.

An agent that can search documentation may not have this problem at all. The result applies to the common case of documentation pasted into a prompt.
