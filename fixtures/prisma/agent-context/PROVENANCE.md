# Where these files came from

Generated by `prisma init` from **prisma 7.9.1** in an empty project, which writes
an agent skill tree into `.agents/skills/` (also `.claude/skills/`, `.windsurf/skills/`).
Only the packs relevant to client construction are committed here; the full install
is 9 packs.

Regenerate with:

    npm init -y && npm i prisma@7.9.1 && npx prisma init --datasource-provider sqlite

These are Prisma's files, not ours. They are committed so the with-context arm is
reproducible and so a change in what Prisma ships shows up as a diff rather than a
silently different score.

**The scored library is `@prisma/client` 7.8.0, which predates these skills.** That is
the point of the measurement: the bare arm is what a project without them gets.
